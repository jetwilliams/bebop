---
name: Check before reporting
description: open/run the output yourself before saying it works; say so if you couldn't
type: feedback
---

Before telling the owner a task is done, check the result yourself: open the file, view the image or frames, play
or inspect the audio, run the tests, load the page. Report what you checked and how. If you could not check
something, say that plainly instead of assuming it's fine.

**Why:** on 2026-09-28 a project agent reported a render as finished; the file was blank. The manager forwarded it
without looking, and the owner found the problem on their phone.

**How to apply:** every report to the owner, especially when the work came from another agent. A project agent's
"done" is a claim to verify, not a fact to forward.
